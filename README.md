## What CapyCalc Does

CapyCalc gives CapybaraGo players a single browser tool for organizing builds and examining character information. Instead of relying on separate notes or spreadsheets, you can use its calculators, planning features, and reference material from one interface.

Its workflow covers character sheet management, inheritance and specialization decisions, damage and attribute calculations, event and activity organization, game data reference, and player card export. The web-based design is intended for quick planning, checking results, and maintaining build records.

## Included Tools

- Keep character sheet and build information organized
- Review inheritance and specialization choices side by side
- Estimate damage for different character configurations
- Recalculate attributes and resulting stat totals
- Plan events, activities, and related in-game tasks
- Consult game data while creating or revising a build
- Export build details as a player card
- Work through a browser-based application designed for web use

Current limitations include:

- A compatible modern browser is required

- Lookup and export behavior may be affected by the browser's handling of local data
